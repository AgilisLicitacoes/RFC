\subsection{Exemplo: LGPD – Lei Geral de Proteção de Dados}
\begin{itemize}
    \item Coletar apenas dados necessários (nome, contato, dados do imóvel).
    \item Evitar dados sensíveis desnecessários.
    \item Solicitar consentimento explícito e exibir política de privacidade clara.
    \item Permitir acesso, correção e exclusão de dados pelo usuário.
\end{itemize}
